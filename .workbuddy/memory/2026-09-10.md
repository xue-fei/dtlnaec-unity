# 2026-09-10

## AEC 对齐链路优化（近端/远端音频对齐）

重构了 dtlnaec-unity 的 AEC 回声消除近远端对齐逻辑，全链路优化：

### 核心缺陷修复
1. **AlignedLoopbackReader 对齐失效**（最严重）：旧实现 `Pull()` 从未使用 `_delaySamples` 补偿，
   只靠锁定时一次性 `ResetReadPos()`，锁定后读指针退化成普通 FIFO，延迟补偿形同虚设。
   重构为：`Pull` 每帧按 `targetRead = _writePos - _delaySamples` 持续对齐，锁定前后都正确。
2. **读指针竞态**：`_readPos`/`_writePos` 改为 `long` 累计（防回绕），Pull 里 clamp 读指针
   不超过写指针；`_writePos < _delaySamples` 时输出静音不读垃圾数据。
3. **校准反馈循环**：`RunCalibration` 原来用已对齐的 `lpbAligned` 做 GCC-PHAT 延迟估计，
   形成"自己校准自己"的反馈，改为用原始 `rawLpb`。
4. **Push 性能**：逐样本 `foreach` 写改为环形分段 `Array.Copy` 批量写入。

### 性能优化（RuntimeProcessor）
- 预分配复用：`_outputFrame`、`_inBlockFft`/`_lpbBlockFft`、`_fullSpectrum`、`_complexInput`、
  `_estimatedBlockTime`，以及 4 个 `DenseTensor`（`_inMag`/`_lpbMag`/`_estimatedBlockTensor`/`_inLpbTensor`）。
- 消除每帧 `ProcessFrame`/`ProcessBlock` 中的 `new float[]`、`new Complex[]`、`new DenseTensor` 分配。
- 复用 buffer 通过 `EnsureBuffers()` 惰性初始化。

### 关键设计要点（备忘）
- 对齐语义：`readPos = writePos - delaySamples`，正值延迟 = mic 滞后 lpb。
- AEC 模型：DTLN-AEC（dtln_aec_128_1/2.onnx），BlockLen=512, BlockShift=128, FftSize=512,
  前 3 帧（PaddingFrames=3）为 zero-padding 预热需丢弃。
- 采样率固定 16kHz，LoopbackCapture 从 Unity 采样率重采样到 16kHz。
